# Network Intrusion Detection System (NIDS)

## Overview

This project demonstrates a basic Network Intrusion Detection System (NIDS) using Suricata on Kali Linux. The system monitors network traffic and generates logs for network analysis and security monitoring.

## Objective

To understand how intrusion detection systems monitor network traffic and help identify suspicious activities.

## Tools Used

* Kali Linux
* Suricata
* Terminal
* Network Utilities (Ping)

## Features

* Real-time network traffic monitoring
* Packet inspection
* Log generation
* Network activity analysis

## Commands Used

```bash
suricata --version
which suricata
sudo suricata --build-info
ip route
sudo suricata -i eth0
ping google.com
sudo ls /var/log/suricata
```
